# MT 마피아 사회자 콘솔

동호회 MT 마피아 게임을 사회자가 진행하기 위한 콘솔입니다. 노트북에서 띄우면 인터넷 없이도 동작합니다.

## 실행

```bash
npm start          # .env 의 PORT (예시 8888, 없으면 3000)
npm run dev        # 파일 변경 감지 + debug 로그
npm start -- --port 3001
```

외부 패키지가 없어 `npm install` 없이 바로 실행됩니다. (Node 18 이상)

처음 실행 전에 `.env.example` 을 `.env` 로 복사하고 `ADMIN_PASSWORD`(사회자 비밀번호)를 정하세요. 없으면 서버가 뜨지 않습니다.

## 화면

| 주소 | 용도 |
|---|---|
| `/` | 사회자 콘솔 — 역할 배정, 낮 회의 타이머, 투표, 밤 진행, 결과 발표. [처음부터]는 역할 다시 배정 또는 같은 배정으로 1일차 낮부터 다시 |
| `/settings/` | 설정 — 역할 · 인원 · 능력 세부 규칙 · 멘트 · 타이머 · 공개 범위 |

- 콘솔 · 설정 화면은 처음 들어갈 때 사회자 비밀번호를 묻습니다(로그인은 30일 유지, 5번 틀리면 1분 잠김).
- 진행 중인 게임은 시작할 때의 설정으로 계속되고, 설정 변경은 다음 게임부터 적용됩니다.

## 데이터 저장

서버의 `DATA_DIR`(기본 `./data`)에 JSON 파일로 저장합니다. 이 폴더는 git 에 올리지 않습니다.

| 파일 | 내용 |
|---|---|
| `settings.json` | 참가자 명단, 역할, 능력 규칙, 멘트, 타이머, 공개 범위 |
| `game.json` | 진행 중인 게임 전체(역할 · 생존 · 밤 지목 · 진행 기록)와 [이전 단계] 기록 |

- 파일마다 `version` 이 있어서, 다른 창이나 PC에서 먼저 저장했으면 덮어쓰지 않고 화면에 알립니다.
- 브라우저에도 사본을 두어, 서버 연결이 끊겨도 계속 진행되고 다시 연결되면 자동으로 올립니다(화면 위쪽 저장 표시 참고).
- Docker 로 띄울 때는 `DATA_DIR` 폴더를 볼륨으로 연결해야 컨테이너를 다시 만들어도 데이터가 남습니다.
- 백업이 필요하면 서버의 `data/settings.json` 을 복사해 두세요.

## 밤 결과 처리 순서

마담 유혹 → 의사 치료 → 마피아 공격(치료 > 방탄) → 스나이퍼 → 연인 동반 사망 → 기자 공개 → 승리 판정

- 유혹: 역할 묶음(의사 2명 등) 중 한 명이라도 유혹당하면 그 밤 능력 무효
- 승리 판정: 처형 직후와 아침 발표 때. 마피아 0명이면 시민 승, 마피아 수가 시민 수 이상이면 마피아 승, 관종이 처형되면 관종 단독 우승

## 역할 규칙 (고정)

설정에서는 인원 · 이름 · 멘트와 횟수(기자 · 방탄 · 스나이퍼)만 바꾸고, 아래 규칙은 고정입니다.

- 공개 범위: 처형 · 밤 사망 모두 기본 "마피아/시민만" ([진행 규칙]에서 변경 가능)
- 연인: 마피아 공격 · 낮 처형으로 한 명이 죽으면 남은 연인도 죽음. 첫날 밤에만 호출해 서로 확인
  - 지목된 연인을 의사가 살리면 둘 다 삶
  - 남은 연인을 의사가 살렸으면 그 연인은 살고, 아침에 연인이었음을 밝힘
- 의사: 의사 자신 · 다른 의사도 살릴 수 있음. 같은 사람을 연속으로 살려도 됨
- 마담: 마피아 팀은 유혹할 수 없음
- 스나이퍼: 의사가 살린 마피아는 죽지 않고, 아침에 아무것도 발표하지 않음(발표하면 마피아인 게 드러남)
- 기자: 역할까지 공개. 그날 밤 죽은 사람(기자 본인이 죽어도)도 공개
- 퇴역군인: 의사가 살렸으면 방탄을 쓰지 않음
