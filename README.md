# MT 마피아 사회자 콘솔

동호회 MT 마피아 게임을 사회자가 진행하기 위한 콘솔입니다. 노트북에서 띄우면 인터넷 없이도 동작합니다.

## 실행

```bash
npm start          # .env 의 PORT (예시 8888, 없으면 3000)
npm run dev        # 파일 변경 감지 + debug 로그
npm start -- --port 3001
```

외부 패키지가 없어 `npm install` 없이 바로 실행됩니다. (Node 18 이상)

처음 실행 전에 `.env.example` 을 `.env` 로 복사하고 `ADMIN_PASSWORD`(사회자 비밀번호)를 정하세요. 없으면 서버가 뜨지 않습니다.

## 화면

| 주소 | 용도 |
|---|---|
| `/` | 사회자 콘솔 — 역할 배정, 낮 회의 타이머, 투표, 밤 진행, 결과 발표. [처음부터]는 역할 다시 배정 또는 같은 배정으로 1일차 낮부터 다시 |
| `/settings/` | 설정 — 역할 · 인원 · 횟수 · 멘트 · 타이머 |

- 콘솔 · 설정 화면은 처음 들어갈 때 사회자 비밀번호를 묻습니다(로그인은 30일 유지, 5번 틀리면 1분 잠김).
- 진행 중인 게임은 시작할 때의 설정으로 계속되고, 설정 변경은 다음 게임부터 적용됩니다.

## 데이터 저장

서버의 `DATA_DIR`(기본 `./data`)에 JSON 파일로 저장합니다. 이 폴더는 git 에 올리지 않습니다.

| 파일 | 내용 |
|---|---|
| `settings.json` | 참가자 명단, 역할, 횟수, 멘트, 타이머 |
| `game.json` | 진행 중인 게임 전체(역할 · 생존 · 밤 지목 · 진행 기록)와 [이전 단계] 기록 |

- 파일마다 `version` 이 있어서, 다른 창이나 PC에서 먼저 저장했으면 덮어쓰지 않고 화면에 알립니다.
- 브라우저에도 사본을 두어, 서버 연결이 끊겨도 계속 진행되고 다시 연결되면 자동으로 올립니다(화면 위쪽 저장 표시 참고).
- Docker 로 띄울 때는 `DATA_DIR` 폴더를 볼륨으로 연결해야 컨테이너를 다시 만들어도 데이터가 남습니다.
- 백업이 필요하면 서버의 `data/settings.json` 을 복사해 두세요.

## 밤 결과 처리 순서

마담 유혹 → 의사 치료 → 마피아 공격(치료 > 방탄) → 스나이퍼(치료 > 방탄) → 연인 동반 사망 → 기자 공개 → 승리 판정

- 밤 행동은 모두 동시에 일어난다. 위 순서는 아침에 결과를 계산하는 순서일 뿐이고, 그 밤에 유혹당하거나 마피아에게 죽게 되는 사람도 평소처럼 불러 지목을 받는다
- 유혹: 역할 묶음(의사 2명 등) 중 한 명이라도 유혹당하면 그 밤 능력 무효. 본인에게 알리지 않고 지목을 받은 뒤 아침 처리에서만 무효
  - 경찰도 지목은 받지만, 결과 대신 "결과를 알려 줄 수 없습니다" 화면을 보여 줌(문구는 설정 > 멘트)
  - 마담이 그 밤 마피아에게 죽어도 유혹은 유효
- 그 밤 마피아에게 죽어서 능력이 무효가 되는 역할은 스나이퍼뿐. 의사 · 경찰 · 기자 · 마담은 죽어도 그 밤 능력이 유효
- 승리 판정: 처형 직후와 아침 발표 때. 마피아 0명이면 시민 승, 마피아 수가 시민 수 이상이면 마피아 승, 관종이 처형되면 관종 단독 우승

## 역할 규칙 (고정)

설정에서는 인원 · 이름 · 멘트와 횟수(기자 · 방탄 · 스나이퍼)만 바꾸고, 아래 규칙은 고정입니다.

- 참가자: 명단 · 고르기 칸 모두 가나다순
- 첫 확인(1일차 낮 전): 마피아(마담 제외)끼리, 연인끼리 서로 얼굴 확인. 마담 · 의사는 부르지 않음
- 공개 범위: 처형 · 저격 사망 · 연인 동반 사망은 "마피아/시민"만 공개 (옵션 없음) — "OOO 님은 선량한 시민이었습니다." / "OOO 님은 마피아였습니다."
- 마피아 공격 사망: 정체를 밝히지 않음 — "간밤, 마피아가 OOO 님을 살해했습니다."
- 아침 발표: 밤사이 무슨 일이든(사망 · 치료 · 방탄 · 기자 공개) 있었으면 "사건이 벌어졌습니다."를 먼저 읽음
- 마피아: 밤에 마피아끼리는 지목할 수 없음(비활성화). 마담이 누구인지 모름
- 마담: 마피아 팀이지만 마피아와 서로 모름. 밤에 마피아 다음에 호출, 횟수 제한 없음, 본인 빼고 누구나 유혹
  - 마피아를 유혹하면 그날 밤 마피아 공격 무효(사망 없음) — 마담이 마피아를 알아내는 유일한 방법
  - 이때 아침에 "사건이 벌어졌습니다." 다음에 위트 문구를 읽음. 문구는 설정 > 멘트에서 바꾸고, 빈 줄로 나눠 여러 개 적으면 그중 하나를 무작위로 읽음
  - 의사 · 스나이퍼 · 기자 · 경찰을 유혹해도(지목을 안 했어도) 아침에 역할별 위트 문구를 읽음. 시민 · 연인 · 퇴역군인 · 관종은 무효로 할 능력이 없어 문구 없음
  - 경찰 조사: 시민 / 기자: "마담"으로 공개
  - 낮 처형 · 스나이퍼 저격: 마피아(팀)로 공개, 마담이라고는 밝히지 않음. 저격한 스나이퍼는 삶
  - 승리 집계는 마피아 팀으로 셈
- 경찰: 결과는 "마피아입니다" 또는 "시민입니다"(마담도 시민). 지목한 사람을 누르면 결과가 전체 화면으로 떠서 그 화면만 경찰에게 보여 줌(콘솔의 명단 · 역할 표시가 보이지 않게). 경찰 차례에는 고르기 칸에 역할 표시를 붙이지 않음
- 연인: 마피아 공격 · 저격 · 낮 처형으로 한 명이 죽으면 남은 연인도 죽음. 밤에는 부르지 않음(첫 확인에서 서로 확인)
  - 지목된 연인을 의사가 살리면 둘 다 삶
  - 남은 연인을 의사가 살렸으면 그 연인은 살고, 아침에 연인이었음을 밝힘
- 의사: 의사 자신 · 다른 의사도 살릴 수 있음. 같은 사람을 연속으로 살려도 됨
- 스나이퍼: 저격하면 결과와 상관없이 기회 1회 사용
  - 마피아(마담 포함)를 맞히면 그 사람만 죽음
  - 시민을 맞히면 그 시민이 죽고, 스나이퍼도 죄책감에 따라 죽음("무고한 시민을 쏜 죄책감에…", 스나이퍼 정체 줄은 따로 없음). 연인을 맞히면 남은 연인도 따라 죽음
  - 의사가 살린 사람은 마피아든 시민이든 둘 다 살고, 같은 문구("저격당했습니다. 하지만 의사가 살렸습니다!")로 발표 — 정체가 드러나지 않게
  - 퇴역군인의 방탄은 저격도 막음(둘 다 삶, 발표함). 같은 밤 마피아 공격이 있으면 방탄을 거기에 먼저 씀
  - 같은 밤 마피아에게 이미 죽은 사람을 쏘면 효과 없음(스나이퍼 삶)
  - 그 밤 마피아에게 지목된 스나이퍼도 평소처럼 불러 지목을 받지만, 의사가 살리지 않아 죽으면 저격은 무효(맞은 사람도 안 죽고 기회도 안 씀)
- 기자: 역할까지 공개. 그날 밤 죽은 사람(기자 본인이 죽어도)도 공개
- 퇴역군인: 방탄은 마피아 공격과 저격을 막음. 의사가 살렸으면 방탄을 쓰지 않음
